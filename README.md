# 서재 · 프리미엄 리더 (오프라인 PWA)

TXT · MD · DOCX 파일을 불러와 읽는 독서 앱이에요. 읽어주기(TTS), 책갈피, 글자 크기 조절,
자동 목차, 페이지 넘김 애니메이션, 다크 모드, 클래식/애플 북스 테마를 지원해요.
폰트와 DOCX 변환 라이브러리를 모두 이 폴더 안에 내장해 두어서, 외부 CDN 없이 완전히
오프라인으로 동작해요.

## GitHub Pages로 배포하기

1. GitHub에 새 저장소를 만들고, 이 폴더 안의 파일 전체(`index.html`, `manifest.json`,
   `sw.js`, `fonts/`, `vendor/`, `icons/`)를 저장소 루트에 올려주세요.
2. 저장소의 **Settings → Pages**로 이동해서, Source를 `Deploy from a branch`로 설정하고
   브랜치는 `main`(또는 사용 중인 브랜치), 폴더는 `/ (root)`를 선택한 뒤 저장하세요.
3. 잠시 후 `https://<사용자명>.github.io/<저장소명>/` 주소로 접속하면 앱이 열려요.

> 저장소 이름이 루트가 아닌 하위 경로(`/저장소명/`)로 배포되는 경우에도, 이 프로젝트는
> 모든 파일을 `./`(상대 경로)로 참조하도록 만들어져 있어서 별도 설정 없이 그대로 동작해요.

## 오프라인 사용

- 배포된 주소에 **인터넷이 연결된 상태로 한 번** 접속하면, 서비스 워커가 페이지·폰트·
  DOCX 변환기·아이콘을 모두 기기에 저장해요. (이건 이 앱만의 제약이 아니라, 모든 PWA가
  최초 1회는 온라인으로 내려받아야 하는 기술적인 이유 때문이에요.)
- 그 이후로는 인터넷이 없어도 앱이 정상적으로 열리고, 파일을 불러와 읽는 것도 전부
  기기 안에서 처리돼요(서버로 전송되지 않아요).
- 아이폰: Safari로 접속 → 공유 버튼 → **홈 화면에 추가**
- 안드로이드: Chrome으로 접속 → 메뉴 → **앱 설치** (또는 주소창의 설치 아이콘)

## 파일 구성

```
index.html              앱 본체
manifest.json            PWA 매니페스트 (앱 이름, 아이콘, 색상)
sw.js                     오프라인 캐싱을 담당하는 서비스 워커
fonts/                    나눔명조 · Noto Serif KR · Noto Sans KR (한글 서브셋 woff2)
vendor/mammoth.browser.min.js   DOCX → HTML 변환 라이브러리
icons/                    앱 아이콘 (192 / 512 / 마스커블 / 애플 터치 아이콘)
```

## 책갈피·마지막 읽던 위치 저장

브라우저에 내장된 저장 기능을 사용해서, 같은 기기·같은 브라우저로 다시 열면 책갈피와
마지막으로 읽던 위치가 그대로 남아 있어요. 다른 기기와는 동기화되지 않아요.

## 알아두면 좋은 점

- 새 버전으로 파일을 다시 올린 뒤에도 예전 버전이 계속 뜬다면, `sw.js` 맨 위의
  `CACHE_VERSION` 값을 바꿔서 다시 배포해 보세요. 서비스 워커가 새 버전을 감지하고
  캐시를 새로 채워요.
- **아이폰 홈 화면에 추가한 앱이 옛날 버전에 머물러 있다면**: iOS는 홈 화면 앱을
  사파리와 분리된 저장공간으로 다루는 경우가 있어서, 사파리에서는 최신 버전이
  보여도 홈 화면 아이콘은 계속 예전 버전을 쓰는 경우가 있어요. 홈 화면 아이콘을
  삭제한 뒤 사파리로 다시 접속해 정상 동작을 확인하고, 그 상태에서 다시
  "홈 화면에 추가" 해주세요.
- 로컬에서 미리보기만 하고 싶다면, 이 폴더에서 `npx serve`(또는 아무 정적 서버)를
  실행한 뒤 `http://localhost:포트`로 접속하세요. `file://`로 직접 열면 서비스 워커와
  일부 브라우저 보안 정책 때문에 정상 동작하지 않아요.
